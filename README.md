# Shri Jayanti Devi Mandir, Jind — website (flat version)

Every file is in this one folder, with no subfolders, so the whole site uploads to GitHub in one go.

## Upload to GitHub
1. In your repo: **Add file → Upload files**.
2. Open this folder on your computer, select everything (Ctrl+A on Windows, Cmd+A on Mac) and drag it in, or click "choose your files" and select all.
3. Click **Commit changes**. The workflow in `.github/workflows/deploy.yml` publishes the site in 1–2 minutes (see the Actions tab).

To edit text later, open any `.html` file on GitHub, click the pencil icon, change it and commit. To swap a photo, upload a new image with the same file name.
